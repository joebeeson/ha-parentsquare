# Security policy

## Reporting a vulnerability

Please use GitHub's private security advisory flow for this repository:

<https://github.com/joebeeson/ha-parentsquare/security/advisories/new>

Do not include Home Assistant config-entry exports, ParentSquare credentials,
cookies, post bodies, attachments, or private calendar URLs in an issue or pull
request. Use synthetic fixtures and redact entity IDs when reporting behavior.
